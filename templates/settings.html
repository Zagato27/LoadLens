Проекты

Проект — это проектная область со своими подключениями, SLA, запросами, промптами и сервисами. В блоке «Что переопределено» видно, откуда берутся настройки: «общие» — из глобальных; «копия общих» — в проекте лежит копия, она не обновится при изменении глобальных; «свои» — значения проекта отличаются от глобальных.

Подключения

Заполните ключевые поля и нажмите «Проверить соединение» — проверка идёт по данным формы ещё до сохранения. Редкие параметры доступны в блоке «Расширенные параметры (JSON)». Пароли и токены показываются как *** и хранятся только на сервере. Каталог источников общий для всех областей; привязка доменов и LLM переопределяются для выбранной области. Хранилище и Confluence общие.

SLA-критерии

Отметьте критерии, которые нужно проверять, и задайте пороги. Главный критерий — целевой RPS: если он достигнут на стабильной ступени, тест считается успешным, а нарушения остальных порогов дают вердикт «Есть риски». Неотмеченные критерии не проверяются.

Контекст тестируемой системы

Описание системы, компонентов, критичных потоков и рисков. Используется как справочный контекст для анализа ИИ и сохраняется снимком вместе с каждым отчётом. Заполняйте то, что знаете: пустые блоки не мешают.

Расширенный режим (JSON)
system_context

Запросы метрик

Запросы метрик по доменам. Нажмите на запрос, чтобы изменить его. Название запроса используется в SLA и при сравнении прогонов, поэтому переименовывайте осторожно. Настройки сервиса переопределяют настройки области.

Расширенный режим (JSON)
queries

Промпты для анализа ИИ

Инструкции модели по доменам. Плейсхолдеры вида {answer_jvm} подставляются автоматически и подсвечены в редакторе — не удаляйте их из итогового промпта. Каждое сохранение попадает в историю, откуда можно восстановить прежнюю версию. Для редактирования нужна выбранная область.

prompt

Сервисы

Сервис — идентификатор тестируемой системы внутри области, для которого создаются отчёты. Здесь можно задать отображаемое имя и выбрать домены анализа; запросы, SLA, промпты и визуализации сервиса настраиваются в соответствующих разделах через выбор сервиса.

Визуализации (metrics_config)

Панели Grafana и логи Loki для отчёта по шаблону Confluence: page_sample_id, page_parent_id, список metrics с grafana_url и logs с фильтрами. Без выбора сервиса редактируется конфигурация всей области (ключ services).

metrics_config

Оформление

Акцентный цвет всей установки: кнопки, логотип и иконка вкладки. Один для всех областей. Светлая и тёмная тема остаются отдельным переключателем в шапке.

Пользователи

Наблюдатель смотрит отчёты, архив, сравнение и прогнозы. Инженер дополнительно запускает анализ, публикует в Confluence, пишет заметки и ставит оценки. Администратор дополнительно меняет настройки и подключения, удаляет данные и управляет пользователями. Блокировка после неудачных входов снимается кнопкой «Разблокировать».
