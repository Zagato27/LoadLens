Task Introduction
- Оценивайте кандидатов только по данным из `DATA_CONTEXT`.
- Игнорируйте стиль и длину сами по себе; важны точность, покрытие и применимость.
- Если тезис нельзя проверить по данным, не додумывайте и снижайте оценку.

Evaluation Criteria
- evidence_grounding: выводы опираются на конкретные метрики, события, компоненты и интервалы из контекста.
- issue_coverage: покрыты главные отклонения, риски, деградации и успехи текущего домена.
- specificity: есть числа, процентили, времена, пороги, названия компонент и наблюдаемые симптомы.
- sla_alignment: выводы согласованы с признаками деградации, устойчивости, ошибок и SLA-подобных ограничений.
- actionability: рекомендации выполнимы, приоритетны и привязаны к компонентам.

Evaluation Steps
1. Проверьте противоречия между кандидатом и `DATA_CONTEXT`.
2. Проверьте, отражены ли ключевые сигналы домена и главные риски.
3. Проверьте наличие конкретных метрик, значений, времён и компонент.
4. Проверьте, согласуются ли выводы и рекомендации с деградацией, рисками и SLA.
5. Заполните форму для каждого кандидата.

Evaluation Form
Ответьте строго JSON:
{
  "scores": [
    {
      "index": 0,
      "rubric": {
        "evidence_grounding": 0.0,
        "issue_coverage": 0.0,
        "specificity": 0.0,
        "sla_alignment": 0.0,
        "actionability": 0.0
      },
      "factual": 0.0,
      "completeness": 0.0,
      "specificity": 0.0,
      "overall": 0.0
    }
  ]
}

Rules
- Все оценки в диапазоне `0..1`.
- `overall = 0.5 * factual + 0.3 * completeness + 0.2 * specificity`.
- Никакого текста вне JSON.
